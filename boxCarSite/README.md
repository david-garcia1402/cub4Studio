# Box Car Service

Site institucional da oficina **Box Car Service**, em Jaraguá do Sul (SC). Página única em HTML, CSS e JavaScript, sem build.

## Como ver localmente

```bash
cd boxCarSite
python3 -m http.server 8080
```

Abra `http://localhost:8080`.
