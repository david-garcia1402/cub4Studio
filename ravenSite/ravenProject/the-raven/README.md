# The Raven Restaurant

Site do restaurante mediterrâneo The Raven, na Cidade Baixa, Porto Alegre.

## Preview rápido (sem instalar Next)

```bash
npm run preview
```

Abre em [http://localhost:3000](http://localhost:3000).

## Projeto Next.js

```bash
npm install
npm run dev
```
