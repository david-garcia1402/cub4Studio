# Restaurante Dom Camilo

Site institucional do restaurante em Niterói, Canoas — RS.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS 4

## Desenvolvimento

```bash
npm install
npm run dev
```

Abre em [http://localhost:3000](http://localhost:3000).

## Produção

```bash
npm run build
npm start
```
