# Redwolf Pizzas — site piloto

Piloto em React + Vite + Tailwind para apresentar à Redwolf (Jaraguá do Sul e Schroeder). Centraliza cardápio, sacola, WhatsApp e Anota AI no lugar do Linktree.

## Rodar

```bash
npm install
npm run dev
```

Abre em [http://localhost:5173](http://localhost:5173).

## Vídeo da apresentação

```bash
npm run record
```

Gera o passeio gravado; o arquivo pronto para apresentar é `public/redwolf-piloto.mp4` (~22s).

## O que é piloto

Preços e alguns sabores são ilustrativos, montados a partir do Instagram público `@redwolfjaragua`, do Linktree e de avaliações públicas. WhatsApp e Anota AI usam os links oficiais da bio.
