# Guacamole Cocina Mexicana — Porto Alegre

Site de conversão da unidade de Petrópolis: reserva por WhatsApp, cardápio do rodízio e delivery.

## Stack

- Next.js 16 (App Router) + React 19
- Tailwind CSS 4
- `next/font` (Fraunces, Outfit, Ephesis)
- Lucide icons

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
