# Outfits — Pipoca e Nino

Fase 0/1 usa só o outfit canônico. Fase 3 libera os extras. Nunca vista o personagem com roupa de IP alheio.

## Canônico (sempre no ar)

- Pipoca: pelo dourado + cachecol coral. Sem camisa, sem sapato.
- Nino: penas + boina azul-céu.

## Fase 3 — outfit B (festa)

- Pipoca: o mesmo cachecol + gravata-borboleta creme minúscula
- Nino: a mesma boina + confete de papel (não plástico realista)

## Fase 3 — outfit C (boa-noite)

- Pipoca: cachecol vira uma manta coral nos ombros
- Nino: boina troca por um gorro de dormir azul, orelha de Pipoca de fora nunca coberta de forma assustadora

## Regras

- Máximo 1 outfit novo por mês
- O rosto não muda com a roupa
- Ainda assim use `duo-hero.png` como referência de identidade
- Se o modelo “inventar” um chapéu de pato ou laço da Minnie: descarte o take
