# Prompts — Suno v5 (música original PT-BR)

Toda faixa publicada precisa de `audio/license.txt` com data, prompt e plano Suno usado.

## Estilo

```
kids dance, bossa-playful, bright ukulele + handclaps + xylophone,
simple Portuguese lyrics, two short verses, earworm chorus,
no rap, no drop agressivo, 95–110 BPM, 30 seconds
```

## Letra-esqueleto (adapte ao episódio)

```
[verse] Pipoca pula, Nino vem
[chorus] Pulo, pulo, Vila do Pulo!
[verse] Cachecol voa no jardim
[chorus] Pulo, pulo, Vila do Pulo!
```

## Proibido no prompt

Nomes de música famosa, “in the style of Cocomelon”, “A Ram Sam Sam”, “Baby Shark”, “tema da Xuxa”, sample de TV.

## Entrega

- Export WAV ou MP3 320
- Duração 28–35s (a montagem corta no beat)
- Sem vocal que imite criança chorando
- Se Suno cantar inglês sem pedido, regenere
